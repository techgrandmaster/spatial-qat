# Data Directory

Curated CC-BY / Public Domain board photos and official PDF datasheets for the Spatial-QAT demo.

## boards/
Pre-seeded development board images (e.g., Arduino Uno R3, ESP32 DevKitC, Raspberry Pi Pico).

## datasheets/
Official PDF datasheets paired with each board.

## labels.jsonl
Gold bounding boxes/polygons and 30 benchmark Q&A pairs for evaluation.

## LICENSES.md
Full attribution & license log for every demo asset.
